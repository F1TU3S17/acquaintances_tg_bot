# acquaintances_tg_bot

Бот для знакомств. Аналог бота Telegram-канала "Леонардо дай винчик".

## Что есть в боте?

В боте имеется возможность создать анкету и находить людей по следующим параметрам: пол, местоположение, возраст и интересы.

Главные отличия от "дайвинчика": возможность более гибкой настройки поиска, простая активация/деактивация анкеты и дополнительные параметры фильтрации.

Пользуйтесь на здоровье в любых проектах, курсовых и, может быть, даже кому-то в дипломе пригодится — кто знает! 😊

## Установка

1. Клонируйте репозиторий.
2. Установите зависимости.
3. Запустите бота.
(Добавьте инструкции по запуску, если нужно)

## Возможности

- Создание и редактирование анкеты
- Гибкий поиск людей по параметрам
- Простая активация/деактивация анкеты
